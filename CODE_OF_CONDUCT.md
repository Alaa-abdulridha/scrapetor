# Code of Conduct

This project follows the [Contributor Covenant, version 2.1][cov].

We expect contributors and maintainers to treat each other with respect
in issues, pull requests, code reviews, and any other project channels.
Harassment, personal attacks, and discriminatory language are not
acceptable.

Reports of unacceptable behaviour can be sent to the maintainer at
**alaa@serpapi.com**. All reports will be reviewed and investigated and
will result in a response that is deemed necessary and appropriate to
the circumstances. The maintainer is obligated to respect the privacy
and security of the reporter.

[cov]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
